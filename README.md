# Дайте світло

Telegram-бот про планові відключення світла в Дніпрі. Наступник [Switchlight](https://github.com/frgttn/switchlight): замість щогодинної розсилки надсилає лише те, що важливо:

- **Публікація**: з'явився графік на завтра;
- **Зміна графіка**, навіть уночі, у форматі «було → стало»;
- **Нагадування** за 30 хвилин до відключення та до повернення світла, окремо про можливі відключення.

Словник термінів: [GLOSSARY.md](GLOSSARY.md). Рішення: [docs/adr](docs/adr).

## Джерела

Основне джерело: сайт DTEK, бо він оновлюється швидше за Yasno і не пропускає нічних змін. Сторінка стоїть за Imperva, тому її відкриває справжній Chromium (Playwright) зі збереженим профілем. Запасне джерело: публічний API Yasno. Якщо DTEK не відповідає довше 30 хвилин, бот переходить на Yasno, але лише коли Yasno знає про новішу зміну. Інакше показує останній графік DTEK з попередженням. Деталі: [ADR 0001](docs/adr/0001-dtek-primary-yasno-fallback.md).

Опитування відбувається кожні 5 хвилин. Час завжди рахується в `Europe/Kyiv`.

## Команди

| Команда | Що робить |
| --- | --- |
| `/start` | Вибір черги кнопками й посилання «Дізнатися свою чергу» |
| `/status` | Що зараз за графіком і коли наступна зміна |
| `/schedule` | Графік на сьогодні й завтра |
| `/settings` | Змінити чергу, вимкнути сповіщення чи нагадування про можливі відключення |
| `/admin` | Тільки для адміна: активне джерело, останні опитування, кількість підписників |
| `/captcha` | Тільки для адміна: відкрити DTEK у браузері сервера для проходження перевірки |

## Запуск на VPS

```sh
cp .env.example .env   # токен бота, ваш chat id, підказка для SSH
docker compose up -d --build
docker compose logs -f bot
```

База SQLite та профіль браузера зберігаються у volume `data`.

### Якщо DTEK показує капчу

Бот сам перейде на Yasno й надішле адміну повідомлення. Щоб повернути DTEK:

1. На своєму комп'ютері: `ssh -L 6080:127.0.0.1:6080 user@your-vps`.
2. Надішліть боту `/captcha`.
3. Відкрийте http://localhost:6080/vnc.html і пройдіть перевірку у вікні браузера.

noVNC слухає тільки на `127.0.0.1` VPS, без SSH-тунелю до нього не дістатися.

## Розробка

Потрібен Node.js 24+: TypeScript запускається без збірки, а `node:sqlite` вбудований.

```sh
npm ci
npx playwright install chromium
npm test
npm run typecheck
npm start              # читає .env
```

Схема бази: [src/db/schema.ts](src/db/schema.ts) (Drizzle поверх `node:sqlite`). Після зміни схеми виконайте `npm run db:generate`: міграції з `drizzle/` застосовуються автоматично під час запуску.

Тести перевіряють розбір обох джерел (на справжніх відповідях з `test/fixtures`), вибір джерела, події, нагадування, тексти й увесь цикл опитування із SQLite у пам'яті. Telegram і Playwright тестами не покриті.
